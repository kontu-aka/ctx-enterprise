# 企業向けCTX 無料AI導入診断（体験版）

Codex・Claude CodeなどのAIコーディング支援ツールを社内で導入する企業の担当者向けに、導入前に会社で決めておきたいことを整理する無料の診断体験版です。

**試作段階です。** このツールはAI利用上のリスクを診断・可視化するものであり、実際のアクセス制御や情報漏えい防止を保証するものではありません。

## 使い方

`index.html` を開くだけで動作します。登録・インストール・APIキーは不要です。会社名や実データの入力も不要で、自社の状況に近いものを選んで、そのままお試しいただけます。

- 9テーマの診断から、結果・改善提案・社内AI利用ルールの草案までを一通り体験できます。
- 回答・生成された草案は、ブラウザのタブのメモリ上だけで扱います。外部送信・保存は行いません。
- 診断結果は印刷・PDF保存ができます。
- お問い合わせフォームからご相談いただけますが、診断の回答内容が送信されることはありません。

## 対象範囲について

本ツールは、Codex・Claude CodeなどのAIコーディング支援ツールの導入を検討する企業向けの検討ツールです。OpenAI社・Anthropic社など、各製品の提供元との提携・公認関係はありません。Codex向け・Claude Code向けの草案は、同じ検討内容の製品名を入れ替えたものであり、製品ごとに異なる安全設定が完了していることを示すものではありません。

## 運営者・お問い合わせ

アプリ内の「運営者情報・お問い合わせ」からご確認いただけます。
