# 企業向けCTX 無料AI導入診断（体験版）

Codex・Claude CodeなどのAIコーディング支援ツールを社内で導入する企業の担当者向けに、導入前に会社で決めておきたいことを整理する無料の診断体験版です。

**試作段階です。** このツールはAI利用上のリスクを診断・可視化するものであり、実際のアクセス制御や情報漏えい防止を保証するものではありません。

## 使い方

`index.html` を開くだけで動作します。登録・インストール・APIキーは不要です。診断には会社名や実データの入力も不要で、自社の状況に近いものを選んで、そのままお試しいただけます。

- 9テーマの診断から、結果・改善提案・社内AI利用ルールの草案までを一通り体験できます。
- 回答・生成された草案は、ブラウザのタブのメモリ上だけで扱います。外部送信・保存は行いません。
- 診断結果は印刷・PDF保存ができます。
- お問い合わせフォームからご相談いただけますが、診断の回答内容が送信されることはありません。

## 対象範囲について

本ツールは、Codex・Claude CodeなどのAIコーディング支援ツールの導入を検討する企業向けの検討ツールです。OpenAI社・Anthropic社など、各製品の提供元との提携・公認関係はありません。Codex向け・Claude Code向けの草案は、同じ検討内容の製品名を入れ替えたものであり、製品ごとに異なる安全設定が完了していることを示すものではありません。

## 問い合わせ送信

Formspreeの既存フォーム `mqpenzan` をポートフォリオと共用します。ポートフォリオのコード・Formspree管理設定は変更しません。
送信ボタンを押したときだけ `https://formspree.io/f/mqpenzan` にPOSTします。送信項目は `company`（任意）、`name`、`email`、`message`、固定の `source=企業向けCTX 無料AI導入診断（体験版）` の5つです。診断回答・草案・模擬承認情報は含めません。
APIキーや外部ライブラリは不要です。名前付きフォーム項目と `Accept: application/json` を使用し、CSPの `connect-src` はこの受付URLだけを許可します。リダイレクトは追跡しません。

- 未設定・未承認URLの場合は送信無効。必須・メール形式・文字数を検証します。
- 既存のハニーポット・2.5秒の入力時間確認を維持します。これらは補助対策で、サーバー側の迷惑送信対策を代替しません。
- 送信中は入力と送信をロックし、閉じて再度開いても維持します。
- 成功表示はサービスによる受付を示し、メール到達保証ではありません。受付済みはこのタブで再送を停止します。
- HTTPエラーは失敗表示とし入力を保持。通信失敗・15秒タイムアウト・不明な応答は結果不明とし、このタブで再送を停止します。自動再送はありません。
- 送信前に閉じると入力を消去。処理中・結果不明の場合はタブ内に保持し、再読込で消えます。Cookie・localStorageには保存しません。
- 問い合わせ対応にFormspreeを利用し、通信に伴うIPアドレス等も同サービスで扱われます。米国等での処理を含む説明と公式ポリシーへのリンクをフォーム内に表示しています。
- 受付先はHuman確認済みの既存設定を使用し、Formspree管理設定は変更していません。利用枠はポートフォリオと共用します。

### 安全なローカル確認

プロジェクトフォルダで `node tests/preview.cjs 8767` を実行し、`http://127.0.0.1:8767/ctx-enterprise/` をChromeで開きます。
このサーバーは127.0.0.1限定です。画面上に「模擬送信」と表示し、受付成功を模擬します。HTTPヘッダーのCSPでも外部通信を禁止するため、実際のFormspreeへの送信はありません。製品ファイルにモックコードを混入させず、確認時だけ注入します。終了は起動ターミナルのCtrl+Cです。
通常の静的サーバーや公開サイトではモックは入りません。**実送信テストは別途Human承認が必要です。**

### テスト

`tests/` はローカル検証専用で、この公開用リポジトリへの保存・サイト配信対象には含めません。以下のコマンドは、検証資産が置かれた制作フォルダで使用します。

`node tests/engine.cjs` で既存診断エンジンを確認します。
`node tests/contact.cjs` は既存のPlaywrightとChromeを使用し、Formspree通信をモック・その他の外部通信を遮断します。Playwrightが別の信頼済みフォルダにある場合、環境変数 `PLAYWRIGHT_MODULE` にそのモジュールパスを指定します。新たなインストールは行っていません。
テスト結果とスクリーンショットは `.git/contact-test-evidence/` に出力され、サイト配信やGit管理の対象になりません。2026年10月28日、Human承認による架空情報1件の実送信でHTTP 200を確認し、HumanがOutlookで通知メールの受信を確認しました。その後のフォームサイズ調整では送信処理を変更せず、モックによる回帰確認を行っています。追加の実送信は行っていません。
