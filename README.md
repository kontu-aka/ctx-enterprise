# 企業向けCTX 無料AI導入診断（体験版）

AI導入を検討する企業・個人事業主が課題を知り、こんつの制作室への有償相談・制作依頼を検討するための無料診断サイトです。

**試作段階です。** このツールはAI利用上のリスクを診断・可視化するものであり、実際のアクセス制御や情報漏えい防止を保証するものではありません。

## 使い方

`index.html` を開くだけで動作します。登録・インストール・APIキーは不要です。診断には会社名や実データの入力も不要で、自社の状況に近いものを選んで、そのままお試しいただけます。

- 5画面（スタート → AI導入診断 → 診断結果 → 改善提案・AI向け指示案 → 提案内容の確認）で、9テーマの課題と改善のヒントを確認できます。03・04・05から既存の問い合わせフォームを開けます。
- 回答・生成されたAI向け指示案は、ブラウザのタブのメモリ上だけで扱います。自動的な外部送信・保存は行いません。AI向け指示案のコピー・ファイル保存は利用者が選んだ場合に端末内で行います。
- 診断結果は印刷・PDF保存ができます。
- お問い合わせフォームからご相談いただけますが、診断の回答内容が送信されることはありません。

05は提案内容・指示案全文・見本との差分を確認する画面です。`#review`から直接開けます。未回答は確認が必要として表示します。模擬承認・保留の操作や状態管理はありません。AI向け指示案はAIに渡す指示文のサンプルであり、従業員向けの社内AI運用ルールの決定や実設定の変更は行いません。

## 対象範囲について

本ツールは、Codex・Claude CodeなどのAIコーディング支援ツールの導入を検討する企業・個人事業主向けの検討ツールです。OpenAI社・Anthropic社など、各製品の提供元との提携・公認関係はありません。Codex向け・Claude Code向けの指示案サンプルは、同じ検討内容の製品名を入れ替えたものであり、製品ごとに異なる安全設定が完了していることを示すものではありません。

## 問い合わせ送信

Formspreeの既存フォーム `mqpenzan` をポートフォリオと共用します。ポートフォリオのコード・Formspree管理設定は変更しません。
送信ボタンを押したときだけ `https://formspree.io/f/mqpenzan` にPOSTします。送信項目は `company`（任意）、`name`、`email`、`message`、固定の `source=企業向けCTX 無料AI導入診断（体験版）` の5つです。診断回答・AI向け指示案は含めません。
APIキーや外部ライブラリは不要です。名前付きフォーム項目と `Accept: application/json` を使用し、CSPの `connect-src` はこの受付URLだけを許可します。リダイレクトは追跡しません。

- 未設定・未承認URLの場合は送信無効。必須・メール形式・文字数を検証します。
- 既存のハニーポット・2.5秒の入力時間確認を維持します。これらは補助対策で、サーバー側の迷惑送信対策を代替しません。
- 送信中は入力と送信をロックし、閉じて再度開いても維持します。
- 成功表示はサービスによる受付を示し、メール到達保証ではありません。受付済みはこのタブで再送を停止します。
- HTTPエラーは失敗表示とし入力を保持。通信失敗・15秒タイムアウト・不明な応答は結果不明とし、このタブで再送を停止します。自動再送はありません。
- 送信前に閉じると入力を消去。処理中・結果不明の場合はタブ内に保持し、再読込で消えます。Cookie・localStorageには保存しません。
- 問い合わせ対応にFormspreeを利用し、通信に伴うIPアドレス等も同サービスで扱われます。米国等での処理を含む説明と公式ポリシーへのリンクをフォーム内に表示しています。
- 受付先はHuman確認済みの既存設定を使用し、Formspree管理設定は変更していません。利用枠はポートフォリオと共用します。

### 安全なローカル確認

プロジェクトフォルダで `node tests/video-preview.cjs 8779` を実行し、`http://127.0.0.1:8779/ctx-enterprise/` をChromeで開きます。
このサーバーは127.0.0.1限定です。画面上に「模擬送信」と表示し、受付成功を模擬します。HTTPヘッダーのCSPでも外部通信を禁止するため、実際のFormspreeへの送信はありません。製品ファイルにモックコードを混入させず、確認時だけ注入します。終了は起動ターミナルのCtrl+Cです。
通常の静的サーバーや公開サイトではモックは入りません。**実送信テストは別途Human承認が必要です。**

### テスト

このcheckpointブランチには、現行R5の検証コードと必要な比較用ハッシュを含めます。アプリ本体はテストコードを読み込みません。ローカル文章編集ツール、Human下書き、バックアップ、旧版テスト、生成画像・ログは保存対象外です。

既存のNode.js・Playwright・Chromeを使用します。Playwrightを別の信頼済みフォルダから使う場合は、環境変数 `PLAYWRIGHT_MODULE` にモジュールの絶対パスを指定してください。新たな外部ライブラリをアプリへ追加していません。

```powershell
node tests/engine.cjs
node tests/diagnosis-compat.cjs
node tests/r5-human-source.cjs
node tests/contact.cjs
node tests/yana-r5-final.cjs
```

- `diagnosis-compat.cjs`：基準commit `b12e4a2abb6f62d812164c77f26b47d1b2e156b4` と診断337ケースを照合します。基準commitを含むGit履歴が必要です。
- `r5-human-source.cjs`：件数0〜9・Codex／Claude Code・回答状態別の86表示を、承認済み文章のSHA-256と照合します。下書きJSONや `.git` 内のローカル資料には依存しません。
- `contact.cjs`：入力検証・成功／失敗・タイムアウト・二重送信防止など19項目を、通信モックと外部通信遮断で検証します。
- `yana-r5-final.cjs`：5画面・9テーマ・3文字サイズ・PC／390px／320px・用語説明・草案コピー／保存・差分・相談導線・動画を確認します。

検証生成物は既定でOSの一時フォルダに出力します。出力先を分ける場合は `R5_COPY_EVIDENCE`、`CONTACT_TEST_EVIDENCE`、`R5_FINAL_OUTPUT` を指定できます。比較基準は `tests/fixtures/` のハッシュで、Human下書きやバックアップそのものは含みません。
